For the research question and findings, see the [project overview](../README.md). The tables below document the inputs and outputs for each stage. 
Follow those dependencies for the analysis you want to reproduce. Where both single-threaded and parallel scripts are listed, use one version.

Pipeline for the thesis's earnings-call AI-discourse analysis. Scripts are grouped by stage in the
order they need to run. Later stages depend on files written by earlier ones. All paths
inside each script are relative to `Code/` (i.e. `../Data/...`).

Files not listed as an "Output" anywhere are read from and never regenerated by this
folder, either external pulls (WRDS downloads, the MSCI ticker list) or hand-built mapping
files. These are called out explicitly under each stage.

### Qualitative Q&A specificity sample (H3, §5.4 discussion)

Each of the three runs is independent (different `--total`), using a simple random draw
within each R&D tercile. All three were rated manually (LLM-assisted, not a script) on the
1-5 specificity scale described in Table B.6's note.

| Script | Purpose | Inputs | Outputs |
|---|---|---|---|
| `sample_qa_exchanges_by_rd.py` | Draws a sample of AI-flagged Q&A snippets stratified by R&D tercile and recovers the full analyst-question/management-answer exchange around each. Run with `--total 45` / `100` / `500` and a distinct `--output` per run. | `../Data/ai_snippets_scored.csv`, `../Data/firm_accounting_panel_combined.csv`, `../Data/fmp_transcripts/` | `../Data/qa_exchange_sample.txt` (45), `../Data/qa_exchange_sample_100.txt`, `../Data/qa_exchange_sample_500.txt` |

The 45- and 100-exchange samples were rated directly into
`Data/qa_exchange_sample_for_manual_read.xlsx` and
`Data/qa_exchange_sample_100_for_manual_read.xlsx`. The 500-exchange sample was rated into
`Data/qa_ratings_500_low.csv` / `_mid.csv` / `_high.csv`, combined into
`Data/qa_ratings_500_combined.csv` (source for the tercile means quoted in the text and
Table B.6).
